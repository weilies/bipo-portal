---
title: Overview
---

These APIs create and maintain users, user roles and role access in BIPO. They are built for the Butter application integration only.

Note: A Butter licence is required.

Note: The Web API user that calls these APIs must have the User Code `#BUTTER_USERS` (at this moment). Any other Web API user is not granted these APIs automatically.

Note: To get a user set up for this, ask Product. It needs special approval from the Product team.

Note: Set up in this order: User Role, then User Role Access, then User.
