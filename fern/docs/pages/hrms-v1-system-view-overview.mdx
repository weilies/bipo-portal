The **GetView** API is a feature that allows users to extract data from the database through pre-configured **SQL Views**, without directly accessing the database. This provides both flexibility and control for data extraction, particularly useful in integration scenarios.

Why we should use GetView?

**Secure Data Access**: GetView only expose necessary data through controlled SQL views, reducing security risks.

**Flexible Integration**: User can query filtered data via API without custom development. GetView accept parameters like EmployeeCode, CompanyCode, ect to filter data dynamically.

**User Friendly**: End users don't need to know the internal schema of the database - they interact with friendly "View Names".

If you don't have access to create SQL Views, contact your Project Manager to setup SQL views.

If you have access to create SQL Views, go to System > Utility > SQL View Screen and create SQL View.

- Ensure it's filtered appropriately with WHERE clauses

- Avoid overly complex joins or non-performant
