**Deployment Steps:**

1. Copy webhook URL from external application  
    e.g. [https://domain.app/flows/trigger/](https://dus.up.railway.app/flows/trigger/9e73ccae-4fb1-46b6-858f-9c48891002a6)xxx
    
2. Login HRMS
    
3. Create new "App Connection"
    
    1. Type = "Webhook"
        
    2. URL = [https://domain.app/flows/trigger](https://domain.app/flows/trigger) (domain + path before dynamic value 'xxx')
        
4. Create new "Event Hook"
    
    1. Tick "Enable"
        
    2. Point to App Connection (created in step 3 above)
        
    3. Navigate to "Scope" tab
        
        1. Set Action to "Add"/"Modify"/"Delete" (determine which event to trigger synchronization to external app)
            
        2. Set "HMAC Secret" if applicable (for auth purpose)
            
        3. Scope (current support "EmployeeProfile" only)  
            note: It covers all employee movements: Employee Master, Org Structure, Salary, Spare Fields etc
            
        4. Webhook (insert "xxx", copied from step 1 above)
            
5. Done
