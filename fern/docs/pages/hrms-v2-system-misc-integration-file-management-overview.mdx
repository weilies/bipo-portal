BIPO HRMS is extended to support file management via API. Each file uploaded from screen contain a unique AttachmentID which can be use to uniquely identify how many files under the attachment

Example:

Single AttachmentID identified two files under the attachment (refer " file list" api)

With the "recordID" responded, use them to further [download ](https://bipo-in-blue.postman.co/workspace/BIPO-WSPC~2640014b-d8e2-495f-8fc6-1487384e4164/request/18494877-72a33b9f-8b2c-426e-bffa-132ed2ce2aed?action=share&source=copy-link&creator=18494877&ctx=documentation) or [delete](https://bipo-in-blue.postman.co/workspace/BIPO-WSPC~2640014b-d8e2-495f-8fc6-1487384e4164/request/18494877-cd47baa5-1204-4833-9689-46c9b925b706?action=share&source=copy-link&creator=18494877&ctx=documentation) the physical file.
